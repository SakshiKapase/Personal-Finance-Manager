# Personal Finance Manager

**Personal Finance Manager** is a Java-based application designed to help users manage and track their personal finances. The project allows users to record daily expenses, analyze them by categories, and generate reports to better manage their financial habits.

## Features
- **Track Income and Expenses**: Allows users to add, view, and categorize their income and expenses.
- **Category-wise Analysis**: Organizes expenses into various categories for better tracking (e.g., Food, Transportation, Utilities).
- **Expense Reporting**: Generates reports to show detailed insights into spending habits.
- **Balance Calculation**: Automatically calculates and updates the current balance based on income and expense entries.
- **Transaction History**: A history of all income and expense transactions with the ability to filter by date and category.
- **User-friendly Interface**: Simple and intuitive console-based user interface.

## Technologies Used
- **Core Java**: The core programming language for implementing the application's features.
- **Object Serialization**: Used to store and retrieve data in a serialized format.
- **File Handling**: Manages reading and writing data from files for data persistence.
- **Collections (List, HashMap, ArrayList)**: Used to manage collections of data and organize expenses.
- **Date Handling**: Handles date-related operations for recording and filtering transactions.
- **I/O Streams**: Used for reading and writing data through input/output streams.

## Data Persistence
- The application currently uses file handling and object serialization for data persistence. Future enhancements can integrate with databases like MySQL for more robust and scalable storage.
